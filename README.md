# 箭雨冲冲冲

一个竖屏跑酷射箭小游戏：手指左右拖动，弓箭自动射出，穿过增益门变强，一路打怪，最后挑战 Boss「卫衣大魔王」。
整个游戏就是一个 `index.html`，不需要安装任何东西，安卓手机用浏览器就能玩。

## 在安卓手机上玩

**方法一：GitHub Pages（推荐，可以装到桌面、离线玩）**

1. 打开仓库的 **Settings → Pages**。
2. *Build and deployment* 里选 **Deploy from a branch**，分支选放游戏的分支（例如 `main`），目录选 `/ (root)`，保存。
3. 等一两分钟后，用手机 Chrome 打开 `https://<你的用户名>.github.io/<仓库名>/`。
4. 点浏览器菜单里的 **添加到主屏幕 / 安装应用**，之后就像普通 App 一样从桌面全屏打开，没网也能玩。

> 私有仓库开 GitHub Pages 需要付费账号；公开仓库免费。

**方法二：直接用文件**

把 `index.html` 发到手机上，用 Chrome 或系统浏览器打开即可（这种方式不能装到桌面）。

## 玩法

- **移动**：手指按住屏幕左右拖动（电脑上用 ← → 或 A / D）。
- **增益门**：每扇门有左右两块牌子，从哪边穿过就拿哪边的效果。红色是负数，**朝它射箭可以把数字一点点打上去**。
  门上的效果有：箭矢数量、射击频率、攻击力、御剑数量、生命。
- **敌人**：绿色小怪、紫色快腿怪、拿棒子的大块头。被碰到会掉一颗心。
- **强化卡**：每打完两波怪，从 3 张卡里选 1 张（多重箭、穿云箭、冰霜箭、烈焰箭、小狐狸宠物、御剑术……）。
- **Boss**：卫衣大魔王会扔火球（看地上的红圈躲开）、推出一排刺球（找缺口钻过去）、召唤小弟。血量低于一半会生气，攻击变快。
- **无尽模式**：打赢 Boss 可以带着本局的强化继续下一关，敌人和 Boss 会越来越强。
- **永久强化**：用金币在主菜单的「永久强化」里升级开局属性。

## Boss 设置

主菜单的「Boss 设置」里可以：

- 改 Boss 的名字；
- **上传一张脸部照片**，拖动、缩放把脸对准椭圆框，Boss 就会顶着这张脸出场；
- 随时点「用卡通脸」换回默认的卡通形象。

照片只保存在当前手机浏览器的本地存储里，不会上传到任何地方，也不在这个仓库里。
